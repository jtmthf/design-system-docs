title: Components

The design system ships **55 components** built on [Base UI](https://base-ui.com)
primitives and styled with Tailwind CSS. Every component is fully typed, theme-aware,
and distributed through the [shadcn registry](/docs/getting-started/registry) — install
any of them with the CLI, open them in v0, or browse them in the
[interactive registry gallery](/components).

Pick a component from the sidebar, or jump to a common starting point below.
