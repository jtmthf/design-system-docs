Use `Input` for any single-line text entry — email addresses, passwords, search
terms, or numeric values. All standard HTML `<input>` types are supported.

Delegates to the Base UI `Input` primitive, which forwards all native `<input>`
props. Set `aria-invalid` to switch the border and ring to destructive colors and
signal validation failure to assistive technology.

## Accessibility

- Renders via the Base UI `Input` primitive, which forwards all native `<input>`
  attributes including `aria-*` props.
- Always associate an `Input` with a visible `<label>` using `htmlFor`/`id` or
  by wrapping both in a `Label` component.
- Use `aria-invalid` together with an error message linked via `aria-describedby`
  so screen readers announce the failure reason.
- `disabled` prevents interaction and sets `pointer-events-none`; prefer keeping
  fields enabled and surfacing errors on submit so they remain keyboard-reachable.
