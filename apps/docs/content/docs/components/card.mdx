Use a card to group related content into a visually distinct panel. It is composed of `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, and `CardFooter`. The `size` prop (`"default"` | `"sm"`) adjusts internal spacing via the `--card-spacing` CSS custom property. Images placed as the first or last direct child are automatically given matching border radii.

## Usage

```tsx twoslash
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "@workspace/ui/components/card";

export function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Project Status</CardTitle>
        <CardDescription>Overview of current sprint</CardDescription>
      </CardHeader>
      <CardContent>
        <p>Everything is on track.</p>
      </CardContent>
    </Card>
  );
}
```

## Accessibility

- A `Card` is a visual grouping container with no implicit ARIA role. When a card represents a discrete item in a list (e.g., a product tile), wrap the list in `role="list"` and apply `role="listitem"` to each card.
- `CardTitle` is a styled `div`, not a heading element. If the card title should be in the document outline, render the title text inside an `<h2>` or appropriate heading level as a child.
- Interactive elements inside the card (buttons, links) retain their native roles and keyboard behavior.
