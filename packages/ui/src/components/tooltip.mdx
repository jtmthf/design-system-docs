# Tooltip

A floating label that explains an interface element on hover or focus. Wrap the
app (or page) in a `TooltipProvider` so open delays and timeouts are shared.

## Usage

- **Default** — a short hint revealed when the trigger is hovered or focused.
- **Open By Default** — initially visible; pair `defaultOpen` with
  `defaultTriggerId` so Base UI can anchor the tooltip to its trigger.
- **Icon Button** — the most common case: clarify an icon-only control. Always
  give the trigger an `aria-label`.
- **Disabled** — suppress the tooltip with the `disabled` prop.

## Do

- Keep tooltip text to a few words; it is a hint, not documentation.
- Use tooltips to label icon-only buttons, in addition to an `aria-label`.
- Wrap the tree in a single `TooltipProvider` so timings stay consistent.

## Don't

- Put essential information or interactive content inside a tooltip — it is not
  reliably reachable on touch devices.
- Rely on a tooltip as the only label for a control.
