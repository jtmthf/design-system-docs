# Button

The primary interactive element. Use buttons for actions that affect the
application state or trigger events.

## Usage

- **Default** — primary action on a page or inside a modal.
- **Secondary** — less prominent action that sits alongside the primary button.
- **Outline** — tertiary actions or toolbars.
- **Destructive** — reserved for irreversible actions such as deletion.
- **Ghost / Link** — subtle or hyperlink-like treatments; use sparingly to
  avoid confusion with navigation.

## Do

- Use a single primary button per section or modal.
- Pair destructive buttons with a confirmation dialog.
- Keep labels concise (one to three words).

## Don't

- Use disabled buttons as the only way to prevent submission — validate on
  submit and show errors instead.
- Nest buttons inside other interactive elements.
