Use `NativeSelect` when you want full platform-native behaviour on mobile and
don't need the customisation a headless select provides. It renders the browser's
own dropdown, so mobile devices present their native picker.

Accepts `size` (`"default"` or `"sm"`) to adjust height and border radius. The
native `size` attribute is excluded to prevent multi-row rendering. Compose with
`NativeSelectOption` and `NativeSelectOptGroup` for options and groups.

## Usage

```tsx twoslash
import {
  NativeSelect,
  NativeSelectOption,
} from "@workspace/ui/components/native-select";

export function Example() {
  return (
    <NativeSelect>
      <NativeSelectOption value="apple">Apple</NativeSelectOption>
      <NativeSelectOption value="banana">Banana</NativeSelectOption>
    </NativeSelect>
  );
}
```

## Accessibility

- Renders a native `<select>`, which receives full keyboard, form association,
  and assistive technology support from the browser.
- Always associate a `Label` via `htmlFor`/`id` so screen readers announce the
  field name.
- `aria-invalid` signals validation failure; pair it with a visible error message
  linked via `aria-describedby`.
- `NativeSelectOptGroup`'s `label` attribute is announced by screen readers as a
  group header within the picker.
