# Alert Dialog

A modal dialog that interrupts the user to confirm or cancel a critical,
destructive, or irreversible action. Unlike a regular dialog, an alert dialog
cannot be dismissed by clicking the backdrop.

## Usage

- **Default** — a trigger button opens a confirmation dialog with cancel and destructive action buttons.
- **Open By Default** — the dialog starts open, useful for session expiry or mandatory acknowledgements.
- **With Media** — a compact dialog with an icon in the header to reinforce the action's severity.

## Do

- Use an alert dialog only for actions that are destructive or cannot be undone.
- Label the confirm button with the specific action (e.g. "Delete account") rather than a generic "OK".
- Always provide a cancel path so the user can back out safely.

## Don't

- Don't use an alert dialog for informational messages — use a Toast or Banner instead.
- Don't stack multiple alert dialogs on top of each other.
