Use a select when the list of options is too long for radio buttons but short
enough to scan visually. The trigger displays the current value; the popup
presents scrollable items with type-to-select and full keyboard navigation.

Built on Base UI's `Select` primitive. Compose `SelectTrigger` and `SelectContent`
around `SelectItem` elements. Use `SelectGroup` with `SelectLabel` to organize
items into labeled sections, and `SelectSeparator` between groups.

## Usage

```tsx twoslash
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@workspace/ui/components/select";

export function Example() {
  return (
    <Select>
      <SelectTrigger className="w-48">
        <SelectValue placeholder="Pick a fruit" />
      </SelectTrigger>
      <SelectContent>
        <SelectItem value="apple">Apple</SelectItem>
        <SelectItem value="banana">Banana</SelectItem>
        <SelectItem value="blueberry">Blueberry</SelectItem>
      </SelectContent>
    </Select>
  );
}
```

## Accessibility

- The trigger renders with `role="combobox"` and the listbox with `role="listbox"`,
  following the WAI-ARIA combobox pattern.
- <kbd>Enter</kbd> or <kbd>Space</kbd> opens the dropdown; arrow keys navigate
  items; <kbd>Escape</kbd> closes without selecting.
- Type any character to jump to the first matching item (type-to-select).
- Disabled items are announced as unavailable and are skipped by keyboard navigation.
