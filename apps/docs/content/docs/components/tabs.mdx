Organises content into panels where only one panel is visible at a time,
selected via a trigger in the tab list. Composed of `TabsList`, `TabsTrigger`,
and `TabsContent`. Built on Base UI's Tabs primitive. Supports
`orientation` (`"horizontal"` | `"vertical"`) and two `TabsList` variants
(`"default"` | `"line"`).

## Usage

```tsx twoslash
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@workspace/ui/components/tabs";

export function Example() {
  return (
    <Tabs defaultValue="account">
      <TabsList>
        <TabsTrigger value="account">Account</TabsTrigger>
        <TabsTrigger value="password">Password</TabsTrigger>
      </TabsList>
      <TabsContent value="account">Account settings</TabsContent>
      <TabsContent value="password">Password settings</TabsContent>
    </Tabs>
  );
}
```

## Guidelines

**Do**

- Match tab labels to the content panel headings so users are not surprised
  when they switch.
- Use `defaultValue` to pre-select the most relevant tab.
- Provide a visible focus ring — the component includes one by default.

**Don't**

- Use tabs for sequential steps where order matters — use a stepper instead.
- Exceed five or six tabs in a single list; prefer a sidebar or dropdown for
  longer navigation sets.
- Mix `variant="line"` and `variant="default"` tab lists on the same page.

## Accessibility

- Implements the [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/).
- <kbd>Tab</kbd> moves focus to the active trigger; <kbd>Arrow</kbd> keys move
  between triggers; <kbd>Enter</kbd> or <kbd>Space</kbd> activates the focused
  tab.
- Each trigger has `role="tab"` and is linked to its panel via `aria-controls`.
- The active trigger carries `aria-selected="true"`; inactive triggers carry
  `aria-selected="false"`.
