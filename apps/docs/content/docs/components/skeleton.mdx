<ComponentPreview name="skeleton-demo" />

Drop a `Skeleton` in place of text, images, or any block element during
data-fetching states. Use `className` to match the exact dimensions and border
radius of the content being replaced so the layout shift on load is minimal.

Renders a `div` with a pulse animation and the `muted` background token — no
additional configuration required.

## Usage

```tsx twoslash
import { Skeleton } from "@workspace/ui/components/skeleton";

export function Example() {
  return (
    <div className="flex flex-col gap-2">
      <Skeleton className="h-4 w-48" />
      <Skeleton className="h-4 w-64" />
    </div>
  );
}
```

## Accessibility

- Skeleton elements are purely visual; they carry no semantic meaning for screen
  readers.
- Use `aria-busy="true"` on the containing region while content is loading and
  remove it once the real content has replaced the skeletons.
- Avoid replacing content that is already rendered with skeletons — only use them
  for genuinely pending data.
