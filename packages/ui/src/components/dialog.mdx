# Dialog

A modal window that interrupts the user to capture attention for critical
decisions, confirmations, or rich forms. Open it from a `DialogTrigger`.

## Usage

- **Default** — a confirmation dialog opened from a trigger button, with cancel
  and confirm actions in the footer.
- For an uncontrolled dialog that starts open, set `defaultOpen` (see the
  **Open By Default** story in the sidebar); it is omitted from this page because
  a modal would cover the documentation.

## Do

- Open dialogs from an explicit `DialogTrigger` so focus returns correctly on close.
- Give every dialog a `DialogTitle` and, where helpful, a `DialogDescription`.
- Pair destructive confirmations with a clearly labelled destructive button.

## Don't

- Use a dialog for non-critical, dismissible information — prefer a `Popover` or toast.
- Stack dialogs on top of one another.
- Remove the close affordance unless the flow genuinely requires a choice.
