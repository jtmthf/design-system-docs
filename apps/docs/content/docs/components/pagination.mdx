Use `Pagination` below lists, tables, or search results to let users move
between pages. `PaginationLink` renders as an `<a>` tag styled as a `Button`.
Set `isActive` on the current page link to apply the `outline` variant and
`aria-current="page"`.

## Usage

```tsx twoslash
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@workspace/ui/components/pagination";

export function Example() {
  return (
    <Pagination>
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious href="/page/1" />
        </PaginationItem>
        <PaginationItem>
          <PaginationLink href="/page/2" isActive>
            2
          </PaginationLink>
        </PaginationItem>
        <PaginationItem>
          <PaginationNext href="/page/3" />
        </PaginationItem>
      </PaginationContent>
    </Pagination>
  );
}
```

## Accessibility

- `Pagination` renders `<nav role="navigation" aria-label="pagination">` — a
  landmark that screen readers can jump to directly.
- The active page link carries `aria-current="page"` so screen readers
  announce it as the current page.
- `PaginationPrevious` and `PaginationNext` carry `aria-label` describing their
  direction.
- `PaginationEllipsis` is `aria-hidden`; its screen-reader-only sibling announces
  "More pages".
- When disabling Previous/Next at the boundaries, add `aria-disabled` together
  with `pointer-events-none` so both mouse and keyboard users cannot activate them.
