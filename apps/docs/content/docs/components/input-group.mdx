---
title: Input Group
description: A composite input container that combines a text field with addons and buttons in a single bordered group.
---

<ComponentPreview name="input-group-demo" />

Use `InputGroup` when a text field needs leading or trailing context — a search
icon, a currency symbol, or an action button. The group renders a shared border
and focus ring coordinated across all children.

Compose `InputGroup` with `InputGroupAddon`, `InputGroupInput`, `InputGroupText`,
`InputGroupButton`, and `InputGroupTextarea`. The `align` prop on `InputGroupAddon`
controls where the addon sits: `"inline-start"` (default), `"inline-end"`,
`"block-start"`, or `"block-end"`.

## Usage

```tsx twoslash
import { SearchIcon } from "lucide-react";
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
  InputGroupText,
} from "@workspace/ui/components/input-group";

export function Example() {
  return (
    <InputGroup>
      <InputGroupAddon>
        <InputGroupText>
          <SearchIcon />
        </InputGroupText>
      </InputGroupAddon>
      <InputGroupInput placeholder="Search…" />
    </InputGroup>
  );
}
```

## Accessibility

- The outer `InputGroup` renders `role="group"`, which tells assistive technology
  that the contained controls are related.
- The focus ring is lifted to the group level so only one ring is visible at a
  time, matching native browser grouped-input behaviour.
- Clicking an `InputGroupAddon` (outside any child button) programmatically
  focuses the first `input` in the group to increase the target size.
- Mark icon-only `InputGroupButton` instances with an `aria-label`.
