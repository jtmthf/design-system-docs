# Switch

A toggle that immediately applies a state change. Use for settings or
preferences where the effect is instant and does not require a submit button.

## Usage

- **Default** — off state; the track is grey and the thumb is left-aligned.
- **Checked** — on state; the track fills with the primary colour and the thumb
  moves right.
- **Small** — compact `sm` size for dense settings panels.
- **Disabled** — non-interactive; use when the setting cannot be changed in the
  current context.
- **Invalid** — signals a required toggle that was not set; pair with an error
  message.
- **With Label** — the recommended composition: label and switch share a click
  target so the full row is interactive.

## Do

- Always pair with a visible label that describes what the switch controls.
- Use switches only for instant actions — if the change requires a save or
  submit, use a checkbox instead.
- Use `defaultChecked` for uncontrolled usage and `checked` + `onCheckedChange`
  for controlled usage.

## Don't

- Use a switch for a destructive or irreversible action without a confirmation
  step.
- Use a switch in place of a checkbox inside a multi-step form that is
  submitted as a whole.
- Rely on colour alone to indicate errors — pair `aria-invalid` with text.
