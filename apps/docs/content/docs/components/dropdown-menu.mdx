Use a dropdown menu for secondary or contextual actions attached to a specific
trigger — user account menus, row actions, or option pickers. Prefer a button
group or inline controls for the primary page action.

Built on Base UI's `Menu.Root` primitive. Compose `DropdownMenu` with
`DropdownMenuTrigger`, `DropdownMenuContent`, and any combination of
`DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`,
`DropdownMenuSub`, `DropdownMenuSeparator`, and `DropdownMenuLabel`.

## Usage

```tsx twoslash
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@workspace/ui/components/dropdown-menu";
import { Button } from "@workspace/ui/components/button";

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger render={<Button variant="outline" />}>
        Actions
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>Edit</DropdownMenuItem>
        <DropdownMenuItem>Duplicate</DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem variant="destructive">Delete</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

## Accessibility

- The popup has `role="menu"` and items have `role="menuitem"` (or
  `menuitemcheckbox` / `menuitemradio`).
- <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> navigate items; <kbd>Enter</kbd>
  or <kbd>Space</kbd> activates the focused item; <kbd>Escape</kbd> closes the menu.
- <kbd>ArrowRight</kbd> opens a `DropdownMenuSubTrigger`; <kbd>ArrowLeft</kbd>
  returns to the parent menu.
- The trigger button exposes `aria-haspopup="menu"` and `aria-expanded`.
