# Avatar

Represents a user or entity visually. Renders an image when one is available
and falls back to initials when it is not. Compose with `AvatarGroup` to show
multiple participants in a compact overlapping stack.

## Usage

- **Default** — standard 32 px circle for most surfaces such as comment threads,
  table rows, and nav bars.
- **Small** — compact 24 px circle for dense surfaces where the full size would
  be distracting.
- **Large** — 40 px circle for profile headers or detail pages where the avatar
  is a primary element.
- **Group** — stack several avatars with `-space-x-2` overlap and append
  `AvatarGroupCount` for overflow.

## Do

- Always supply `AvatarFallback` with legible initials so the UI degrades
  gracefully when an image fails to load.
- Keep initials to two characters maximum.
- Provide an `aria-label` on the wrapping element when the avatar conveys
  identity in a context where the user's name is not otherwise visible.

## Don't

- Use avatars as the sole indicator of identity without a visible name nearby.
- Render more than five or six avatars in a group without an overflow count.
- Scale avatars with arbitrary `className` sizes — use the `size` prop so the
  badge and fallback text scale correctly.
