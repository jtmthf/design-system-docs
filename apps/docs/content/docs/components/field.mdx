Use `Field` to give every form control a consistent label, description, and
validation error layout without repeating spacing and alignment logic. It
renders a `div[role="group"]` and wires the `data-invalid` attribute to
destructive color theming.

Compose with `FieldLabel`, `FieldDescription`, and `FieldError` for most
cases. Use `FieldGroup` and `FieldSet` / `FieldLegend` to group related fields.
Use `FieldContent` and `FieldTitle` for horizontal layouts with multi-line
descriptions.

## Usage

```tsx twoslash
import { Field, FieldDescription, FieldLabel } from "@workspace/ui/components/field";
import { Input } from "@workspace/ui/components/input";

export function Example() {
  return (
    <Field>
      <FieldLabel htmlFor="email">Email address</FieldLabel>
      <Input id="email" type="email" placeholder="ada@example.com" />
      <FieldDescription>We&apos;ll never share your email.</FieldDescription>
    </Field>
  );
}
```

## Accessibility

- `Field` renders `role="group"` so grouped fields are announced together by
  screen readers.
- Link `FieldLabel` to its control via `htmlFor` or by nesting the control
  inside the label.
- `FieldError` renders `role="alert"` so validation messages are announced
  immediately when they appear.
- `FieldSet` + `FieldLegend` use semantic `<fieldset>` and `<legend>` elements
  that browsers and assistive technologies understand natively.
