# Dropdown Menu

A floating menu anchored to a trigger button. Use it for secondary actions,
navigation, or contextual commands. Wrap a label and its items in a
`DropdownMenuGroup` so grouped sections are announced correctly.

## Usage

- **Default** — a grouped menu with a label and a destructive action.
- **With Icons And Shortcuts** — a full account menu with icons, keyboard
  shortcuts, nested submenus, and multiple groups.
- **With Checkbox Items** — toggle independent options with `DropdownMenuCheckboxItem`.
- **With Radio Items** — enforce a single selection with `DropdownMenuRadioGroup`.
- **With Destructive Item** — style irreversible actions with `variant="destructive"`.

## Do

- Wrap a `DropdownMenuLabel` together with its items inside a `DropdownMenuGroup`.
- Use `DropdownMenuSeparator` to divide unrelated groups of actions.
- Reserve the `destructive` item variant for irreversible actions.

## Don't

- Use a dropdown menu for primary page actions — use buttons.
- Place a `DropdownMenuLabel` outside of a group (Base UI requires a group context).
- Nest more than one level of submenu where a dedicated page would be clearer.
