A React component library of 55 accessible components built on
[Base UI](https://base-ui.com) primitives, styled with
[Tailwind CSS v4](https://tailwindcss.com) design tokens, and packaged for use
across a Turborepo monorepo or copied into any project via a shadcn-compatible
registry.

Every component page includes live examples, the verbatim source, and a prop
table generated from the real TypeScript types — so the docs never drift from
the implementation.

## Get started

- [Installation](/docs/getting-started/installation) — add the package to a
  workspace app or pull components into an external project.
- [Theming](/docs/getting-started/theming) — the token system, color, radius,
