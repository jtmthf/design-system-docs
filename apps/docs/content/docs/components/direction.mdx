<ComponentPreview name="direction-demo" />

Wrap a subtree in `DirectionProvider` to apply `"ltr"` or `"rtl"` reading
direction to all Base UI primitives inside it without modifying the HTML `dir`
attribute directly. Use `useDirection` in child components when you need to
read the current direction value.

Re-exported from `@base-ui/react/direction-provider`. Useful for applications
supporting Arabic, Hebrew, or other right-to-left languages.

## Usage

```tsx twoslash
import { DirectionProvider } from "@workspace/ui/components/direction";

export function App() {
  return (
    <DirectionProvider direction="rtl">
      <div dir="rtl">Right-to-left content goes here.</div>
    </DirectionProvider>
  );
}
```

## Accessibility

- Set the HTML `dir` attribute on the wrapping element alongside
  `DirectionProvider` so the browser also mirrors text rendering and
  bidirectional algorithm (e.g. `<div dir="rtl">`).
- Base UI components automatically invert logical properties (start/end, left/right)
  when the direction is `"rtl"`.
