# Popover

A floating card anchored to a trigger element. Popovers are lighter than dialogs
and do not disable the rest of the page.

## Usage

- **Default** — a trigger that opens a floating card with rich content.
- **Open By Default** — initially open; pair `defaultOpen` with `defaultTriggerId`
  so Base UI anchors the popup to its trigger.
- **With Form** — embed a small form for inline editing without navigating away.

## Do

- Use a popover for secondary, non-blocking content tied to a trigger.
- Give a title and description so the popup is self-explanatory.
- Reserve `modal` for cases that genuinely require trapping focus.

## Don't

- Use a popover for critical, must-acknowledge decisions — use a `Dialog`.
- Pack long-form or scrolling content into a popover.
