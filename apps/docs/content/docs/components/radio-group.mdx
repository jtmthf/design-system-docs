Use a radio group when the user must pick exactly one option from a small, visible
list. Always pair each `RadioGroupItem` with a `Label` — the label provides the
accessible name and enlarges the hit target.

Built on Base UI's `RadioGroup` and `Radio` primitives. Manages a single active
value across all child items, supports controlled (`value` + `onValueChange`) and
uncontrolled (`defaultValue`) modes, and exposes a `disabled` prop for the entire
group.

## Usage

```tsx twoslash
import { Label } from "@workspace/ui/components/label";
import { RadioGroup, RadioGroupItem } from "@workspace/ui/components/radio-group";

export function Example() {
  return (
    <RadioGroup defaultValue="compact">
      <Label className="flex items-center gap-2">
        <RadioGroupItem value="comfortable" />
        Comfortable
      </Label>
      <Label className="flex items-center gap-2">
        <RadioGroupItem value="compact" />
        Compact
      </Label>
    </RadioGroup>
  );
}
```

## Accessibility

- Each item renders a native radio-like button; the group follows the
  [WAI-ARIA radio group pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/).
- <kbd>Tab</kbd> moves focus into the group; arrow keys move between items within
  the group.
- Always wrap each item in a `Label` — the accessible name comes from the label
  text.
- Use `aria-invalid` on individual items to surface validation errors; pair with a
  visible error message.
