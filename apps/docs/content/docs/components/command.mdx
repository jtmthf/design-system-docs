Use a command palette to give users a single, discoverable entry point to
navigate or trigger actions without leaving the keyboard. Embed it inline or
wrap it in `CommandDialog` for a spotlight-style modal experience.

Built on the `cmdk` primitive. Compose `Command` with `CommandInput`,
`CommandList`, `CommandGroup`, `CommandItem`, and optionally `CommandSeparator`
and `CommandShortcut`. For a modal variant, use `CommandDialog` which composes
the `Dialog` component internally.

## Usage

```tsx twoslash
import {
  Command,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
} from "@workspace/ui/components/command";

export function Example() {
  return (
    <Command>
      <CommandInput placeholder="Search commands..." />
      <CommandList>
        <CommandEmpty>No results found.</CommandEmpty>
        <CommandGroup heading="Actions">
          <CommandItem>Open file</CommandItem>
          <CommandItem>New project</CommandItem>
        </CommandGroup>
      </CommandList>
    </Command>
  );
}
```

## Accessibility

- <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> move between items; <kbd>Enter</kbd>
  activates the focused item; <kbd>Escape</kbd> closes a `CommandDialog`.
- Built-in filtering scores items against the search query; pass a custom
  `filter` function or `shouldFilter={false}` for pre-filtered data.
- `CommandDialog` composes an accessible modal with a visually-hidden title and
  description that screen readers announce on open.
