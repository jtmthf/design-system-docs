Use a progress bar to show task completion — file uploads, multi-step forms, or
background processing. Compose `ProgressLabel` for a visible accessible name and
`ProgressValue` for a numeric readout alongside the track.

Built on Base UI's `Progress` primitive. The `value` prop (0–100) controls how
much of the track is filled. `ProgressTrack` and `ProgressIndicator` are rendered
automatically inside `Progress`.

## Usage

```tsx twoslash
import { Progress, ProgressLabel, ProgressValue } from "@workspace/ui/components/progress";

export function Example() {
  return (
    <Progress value={60} className="w-80">
      <ProgressLabel>Uploading</ProgressLabel>
      <ProgressValue />
    </Progress>
  );
}
```

## Accessibility

- Renders `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and
  `aria-valuemax` managed by Base UI.
- Provide either a visible `ProgressLabel` or an `aria-label` prop so screen
  readers can announce what is progressing.
- When no `value` is set the bar enters indeterminate mode; Base UI omits
  `aria-valuenow` in that state.
