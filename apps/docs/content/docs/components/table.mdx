Wraps a native `<table>` in an overflow container and composes it from
`TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`,
`TableCell`, and `TableCaption`. Use this for data with a clear column-and-row
structure. For interactive sorting or pagination, add your own logic on top.

## Usage

```tsx twoslash
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@workspace/ui/components/table";

export function Example() {
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>Name</TableHead>
          <TableHead>Amount</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow>
          <TableCell>Alice</TableCell>
          <TableCell>$50.00</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

## Guidelines

**Do**

- Give every table a visible caption or an `aria-label` on the wrapping element.
- Keep column headers short and descriptive.
- Right-align monetary and numeric columns so digits line up visually.

**Don't**

- Use a table for layout or for content that has no meaningful column structure.
- Omit `TableHeader` — without it, screen readers cannot announce column
  context.
- Put interactive controls inside cells without ensuring each has its own
  accessible label.

## Accessibility

- Uses semantic HTML elements (`<table>`, `<thead>`, `<tbody>`, `<th>`, `<td>`)
  so assistive technology can interpret the column-and-row structure.
- Always include a `<TableCaption>` or `aria-label` to give the table an
  accessible name.
- Column headers rendered via `<TableHead>` (`<th>`) are automatically
  associated with their data cells.
