# Sidebar

A full-featured application sidebar with collapse support, a keyboard shortcut
(⌘B / Ctrl+B), and automatic mobile-sheet behaviour. Compose
`SidebarProvider`, `Sidebar`, and `SidebarInset` to build an app shell, then
fill the sidebar with `SidebarHeader`, `SidebarContent`, `SidebarGroup`, and
`SidebarMenu` primitives.

## Usage

- **Default** — a standard left sidebar with offcanvas collapse.
- **Icon Collapsible** — collapses to a narrow icon rail rather than sliding
  off-screen.
- **Floating** — the sidebar renders as a card slightly inset from the viewport
  edge.
- **Right Side** — sidebar anchored to the right edge of the viewport.

## Do

- Always wrap your layout with `SidebarProvider` — it owns the open/closed
  state and wires up the keyboard shortcut.
- Pair `Sidebar` with `SidebarInset` so the main content area shifts correctly
  when the sidebar collapses.
- Use `SidebarTrigger` inside the main content header so users can toggle the
  sidebar without reaching into the panel.
- Set `isActive` on the `SidebarMenuButton` that corresponds to the current
  route.

## Don't

- Render `Sidebar` outside a `SidebarProvider` — `useSidebar` will throw.
- Mix `variant="inset"` with `collapsible="icon"` — the icon rail width
  calculation doesn't account for the inset padding.
- Place primary page actions inside the sidebar — they become invisible when
  the sidebar is collapsed.
