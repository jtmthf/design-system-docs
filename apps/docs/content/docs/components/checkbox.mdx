Use a checkbox for independent on/off choices — accepting terms, enabling a
feature, or filtering a list. Always pair it with a `Label` so the option is
announced by screen readers.

Built on Base UI's `Checkbox.Root` primitive, which owns checked state,
keyboard handling, and ARIA semantics. The check icon is animated in and out
via an internal `Indicator` and CSS transitions.

## Accessibility

- Renders a native `<button>` with `role="checkbox"` via the Base UI primitive,
  so it is fully keyboard operable.
- <kbd>Space</kbd> toggles the checked state.
- Always associate a `<label>` via `htmlFor` or by wrapping the checkbox as a
  child — unlabelled checkboxes are inaccessible to screen reader users.
- Use `aria-invalid` to signal validation failures; pair it with a visible
  error message.
