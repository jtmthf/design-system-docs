# Aspect Ratio

Constrains a child element to a fixed width-to-height ratio using a single CSS
custom property. Use it to prevent layout shift when loading images, videos,
maps, or iframes.

## Usage

- **Widescreen (16 ∶ 9)** — the default; suits hero images and video embeds.
- **Square (1 ∶ 1)** — profile pictures, thumbnails, and avatar crops.
- **Classic (4 ∶ 3)** — legacy video, photograph crops, and map embeds.

## Do

- Wrap the child in `AspectRatio` and apply `object-cover` / `object-contain`
  to images so they fill the box without distorting.
- Give the outer container a width (`w-full`, `w-64`, etc.) — `AspectRatio`
  derives its height from the width and the ratio.
- Use the `ratio` prop with a plain arithmetic expression (`16 / 9`) rather than
  a pre-calculated decimal for readability.

## Don't

- Nest `AspectRatio` inside a flex or grid item that has a fixed height — the
  ratio will fight the parent's height constraint.
- Apply a height class directly on `AspectRatio` — the component sets height
  via the ratio.
- Use `AspectRatio` for text content where natural document flow is preferable.
