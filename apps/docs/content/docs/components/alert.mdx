Use an alert to surface important, time-relevant information without interrupting the user's flow. It is composed of `AlertTitle`, `AlertDescription`, and the optional `AlertAction` slot. Place an SVG icon as a direct child to activate the two-column icon layout. The `variant` prop switches between `"default"` and `"destructive"` styles.

## Usage

```tsx twoslash
import {
  Alert,
  AlertTitle,
  AlertDescription,
} from "@workspace/ui/components/alert";
import { TerminalIcon } from "lucide-react";

export function Example() {
  return (
    <Alert>
      <TerminalIcon />
      <AlertTitle>Heads up!</AlertTitle>
      <AlertDescription>
        You can add components to your app using the CLI.
      </AlertDescription>
    </Alert>
  );
}
```

## Accessibility

- The root element carries `role="alert"`, so screen readers announce the content immediately when it appears in the DOM.
- Alerts should describe the status and, when relevant, the corrective action the user can take.
- Avoid using `role="alert"` for content that is present on page load — reserve it for dynamically injected feedback.
