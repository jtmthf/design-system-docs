Use `Item` as the row primitive for structured list content. Compose it with
`ItemMedia`, `ItemContent`, `ItemTitle`, `ItemDescription`, and `ItemActions` to
build richly structured rows with icons, text, and trailing controls.

`Item` renders via Base UI's `useRender`, making the underlying element
polymorphic through the `render` prop. `ItemGroup` wraps multiple items in a
`role="list"` container with consistent gap. `ItemSeparator` inserts a horizontal
rule between items.

## Usage

```tsx twoslash
import {
  Item,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@workspace/ui/components/item";

export function Example() {
  return (
    <Item variant="outline">
      <ItemMedia variant="icon" />
      <ItemContent>
        <ItemTitle>Report.pdf</ItemTitle>
        <ItemDescription>Last modified 2 days ago</ItemDescription>
      </ItemContent>
    </Item>
  );
}
```

## Accessibility

- `ItemGroup` renders `role="list"`, which announces the count of items to screen
  readers that suppress list semantics on unstyled lists.
- `ItemSeparator` is a visual separator only; it carries no ARIA role.
- Interactive `Item` elements (rendered as `<a>` or `<button>` via the `render`
  prop) inherit standard keyboard navigation; ensure they have a visible focus
  ring.
- `ItemActions` buttons should carry `aria-label` when the icon alone is not
  descriptive.
