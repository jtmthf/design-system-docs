<ComponentPreview name="avatar-demo" />

Use an avatar to represent a user or entity visually. It is composed of `AvatarImage` and `AvatarFallback` — when the image fails to load, the fallback is shown automatically. The `size` prop (`"sm"` | `"default"` | `"lg"`) controls the diameter. An `AvatarBadge` can be overlaid for status indicators, and multiple avatars can be stacked inside an `AvatarGroup`. Built on Base UI's `Avatar` primitive.

## Usage

```tsx twoslash
import {
  Avatar,
  AvatarImage,
  AvatarFallback,
} from "@workspace/ui/components/avatar";

export function Example() {
  return (
    <Avatar size="lg">
      <AvatarImage src="/profile.jpg" alt="Jane Doe" />
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
  );
}
```

## Accessibility

- Always supply `alt` text on `AvatarImage` so screen readers can announce the user's name.
- When using `AvatarBadge` for status, pair it with a visually hidden label or `aria-label` on the parent to communicate the status to assistive technology.
- `AvatarGroupCount` is a visual-only overflow indicator; provide a full list elsewhere in the interface if the hidden members are actionable.
