Renders a `Loader2` icon with `role="status"` and `aria-label="Loading"` so
screen readers announce the loading state automatically. Use `className` to
control size and color. For measurable progress, use `Progress` instead.

## Guidelines

**Do**

- Size the spinner to match its context — icon size for inline use, larger for
  full-section loaders.
- Keep the spinner visible for the full duration of the async operation.
- Use `text-{color}` classes to match the surrounding text color when embedding
  inside buttons or on colored surfaces.

**Don't**

- Use a spinner for operations that finish in under 300 ms — a brief flash is
  more jarring than nothing.
- Use a spinner when progress can be measured — reach for `Progress` instead.
- Show multiple spinners simultaneously on the same view.

## Accessibility

- Renders with `role="status"` so assistive technology announces the loading
  state without requiring focus.
- The default `aria-label="Loading"` provides an accessible name; override it
  via `aria-label` when a more specific description is available.
