Use a collapsible to progressively disclose information — FAQ answers, settings
panels, or any content the user may not need at first glance. It pairs a trigger
element with a panel that animates open and closed.

Built on Base UI's `Collapsible.Root` primitive. Compose it with
`CollapsibleTrigger` (any focusable element) and `CollapsibleContent` (the
animated panel). State can be uncontrolled (`defaultOpen`) or controlled (`open`
+ `onOpenChange`).

## Usage

```tsx twoslash
import {
  Collapsible,
  CollapsibleTrigger,
  CollapsibleContent,
} from "@workspace/ui/components/collapsible";

export function Example() {
  return (
    <Collapsible>
      <CollapsibleTrigger>Toggle</CollapsibleTrigger>
      <CollapsibleContent>Hidden content revealed on open.</CollapsibleContent>
    </Collapsible>
  );
}
```

## Accessibility

- The trigger exposes `aria-expanded` that reflects the current open state.
- <kbd>Enter</kbd> or <kbd>Space</kbd> on a focused trigger toggles the panel.
- Wrap the trigger in a heading element when the collapsible forms a
  disclosure pattern similar to an accordion.
