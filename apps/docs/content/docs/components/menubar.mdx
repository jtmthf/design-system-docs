title: Menubar

<ComponentPreview name="menubar-demo" />

Use `Menubar` as a persistent top-level navigation control for editor-style
applications where commands are grouped into named menus (File, Edit, View, etc.).
Each menu opens on click and supports keyboard navigation between menus.

Built on Base UI's `Menubar` primitive. Wraps one or more `MenubarMenu` components,
each composed of a `MenubarTrigger` and `MenubarContent`. `MenubarMenu` delegates
to `DropdownMenu` internally.

## Usage

```tsx twoslash
import {
  Menubar,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarSeparator,
  MenubarTrigger,
} from "@workspace/ui/components/menubar";

export function Example() {
  return (
    <Menubar>
      <MenubarMenu>
        <MenubarTrigger>File</MenubarTrigger>
        <MenubarContent>
          <MenubarItem>New File</MenubarItem>
          <MenubarSeparator />
          <MenubarItem>Exit</MenubarItem>
        </MenubarContent>
      </MenubarMenu>
    </Menubar>
  );
}
```

## Accessibility

- Follows the [ARIA menubar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/).
- <kbd>←</kbd> / <kbd>→</kbd> move focus between top-level triggers;
  <kbd>↑</kbd> / <kbd>↓</kbd> move within an open menu.
- <kbd>Enter</kbd> or <kbd>Space</kbd> opens the focused trigger's menu and
  activates a focused item.
- <kbd>Esc</kbd> closes the open menu and returns focus to the trigger.
- `MenubarCheckboxItem` exposes `aria-checked`; `MenubarRadioItem` exposes
  `role="menuitemradio"` and `aria-checked`.
