---
title: Context Menu
description: A menu that appears on right-click or long-press over a trigger area.
---

<ComponentPreview name="context-menu-demo" />

Use a context menu for actions that are tied directly to a specific target
element — file operations, row actions in a table, canvas interactions. The
menu appears at the pointer position when the user right-clicks (or long-presses
on touch devices).

Built on Base UI's `ContextMenu.Root` primitive. Compose it with
`ContextMenuTrigger`, `ContextMenuContent`, and any combination of
`ContextMenuItem`, `ContextMenuCheckboxItem`, `ContextMenuRadioGroup`,
`ContextMenuSub`, `ContextMenuSeparator`, and `ContextMenuLabel`.

## Usage

```tsx twoslash
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@workspace/ui/components/context-menu";

export function Example() {
  return (
    <ContextMenu>
      <ContextMenuTrigger>Right-click me</ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>Cut</ContextMenuItem>
        <ContextMenuItem>Copy</ContextMenuItem>
        <ContextMenuItem variant="destructive">Delete</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

## Accessibility

- The popup has `role="menu"` and items have `role="menuitem"` (or
  `menuitemcheckbox` / `menuitemradio`).
- <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> navigate items; <kbd>Enter</kbd>
  or <kbd>Space</kbd> activates the focused item; <kbd>Escape</kbd> closes the menu.
- <kbd>ArrowRight</kbd> opens a submenu trigger; <kbd>ArrowLeft</kbd> returns
  to the parent menu.
- The `ContextMenuTrigger` area applies `select-none` to prevent text selection
  during the right-click gesture.
