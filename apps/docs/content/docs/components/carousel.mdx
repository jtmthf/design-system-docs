Use a carousel to cycle through a series of content items — images, cards, or arbitrary content — within a constrained viewport. It is composed of `CarouselContent`, `CarouselItem`, `CarouselPrevious`, and `CarouselNext`. Use the `orientation` prop to switch between `"horizontal"` (default) and `"vertical"` scroll axes. Pass Embla options via `opts` and plugins via `plugins`. Use `setApi` to receive the Embla API instance for programmatic control.

## Usage

```tsx twoslash
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselPrevious,
  CarouselNext,
} from "@workspace/ui/components/carousel";

export function Example() {
  return (
    <Carousel opts={{ loop: true }}>
      <CarouselContent>
        <CarouselItem>Slide 1</CarouselItem>
        <CarouselItem>Slide 2</CarouselItem>
        <CarouselItem>Slide 3</CarouselItem>
      </CarouselContent>
      <CarouselPrevious />
      <CarouselNext />
    </Carousel>
  );
}
```

## Accessibility

- The root element carries `role="region"` and `aria-roledescription="carousel"`.
- Each `CarouselItem` carries `role="group"` and `aria-roledescription="slide"`.
- `CarouselPrevious` and `CarouselNext` include visually hidden "Previous slide" / "Next slide" labels for screen readers.
- <kbd>ArrowLeft</kbd> and <kbd>ArrowRight</kbd> scroll the carousel when focus is inside it; <kbd>Tab</kbd> moves focus to the navigation buttons.
- Navigation buttons are `disabled` automatically when there are no more slides to scroll to in that direction.
