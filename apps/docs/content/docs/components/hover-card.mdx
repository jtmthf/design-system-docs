Use a hover card to surface supplemental information about a linked entity — a
user profile, a file, or a document — without requiring a click. It opens after
the pointer enters the trigger and closes when both the trigger and the popup
lose focus or pointer contact.

Built on Base UI's `PreviewCard` primitive. Compose `HoverCard`, `HoverCardTrigger`,
and `HoverCardContent`; all positioning and open/close timing is handled by the
primitive.

## Usage

```tsx twoslash
import {
  HoverCard,
  HoverCardTrigger,
  HoverCardContent,
} from "@workspace/ui/components/hover-card";

export function Example() {
  return (
    <HoverCard>
      <HoverCardTrigger>@username</HoverCardTrigger>
      <HoverCardContent>
        <p>Joined January 2020</p>
      </HoverCardContent>
    </HoverCard>
  );
}
```

## Accessibility

- The popup is not a dialog and does not trap focus — it is purely informational.
- `HoverCardTrigger` should wrap a focusable element so keyboard users can
  activate the card with <kbd>Tab</kbd>.
- The card opens on both pointer hover and keyboard focus, then closes when
  either loses its respective attention.
- Avoid placing interactive controls inside the card; users who trigger it via
  keyboard cannot move focus into it.
