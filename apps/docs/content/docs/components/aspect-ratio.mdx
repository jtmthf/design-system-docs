---
title: Aspect Ratio
description: A container that constrains its content to a specific width-to-height ratio.
---

<ComponentPreview name="aspect-ratio-demo" />

Use `AspectRatio` to keep images, videos, maps, or any embed proportional regardless of the available width. The `ratio` prop is required and accepts any positive number such as `16 / 9`, `4 / 3`, or `1`. Internally, the ratio is applied via a CSS custom property `--ratio` and `aspect-(--ratio)`.

## Usage

```tsx twoslash
import { AspectRatio } from "@workspace/ui/components/aspect-ratio";

export function Example() {
  return (
    <AspectRatio ratio={16 / 9}>
      <img
        src="/hero.jpg"
        alt="Hero"
        className="h-full w-full rounded-md object-cover"
      />
    </AspectRatio>
  );
}
```

## Accessibility

- `AspectRatio` is a purely visual container — it adds no ARIA semantics.
- Always provide descriptive `alt` text on any `<img>` placed inside the container.
