# Sheet

A sliding panel anchored to the edge of the viewport. Use Sheets for navigation
menus, settings panels, and supplemental content that should stay in context
alongside the main page.

## Usage

- **Default** — slides in from the right with a header, body content, and footer actions.
- **Left Side** — anchored to the left edge for primary navigation menus.
- **Bottom Sheet** — anchored to the bottom, common on mobile for action menus.
- **Without Close Button** — hides the built-in X button when custom dismiss controls are preferred.

## Do

- Use a sheet when the user needs to reference or interact with the main content while the panel is open.
- Provide a clear dismiss mechanism — either the built-in close button or a footer action.
- Match the `side` to the directionality of the content (navigation on the left, details on the right).

## Don't

- Don't use a sheet for destructive confirmations — use an AlertDialog instead.
- Don't remove `showCloseButton` without adding another dismiss affordance.
