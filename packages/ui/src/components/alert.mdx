# Alert

A callout that attracts attention without interrupting the user flow.
Compose with `AlertTitle`, `AlertDescription`, and optionally an icon.

## Usage

- **Default** — general notices, tips, or non-urgent information.
- **Destructive** — errors that require immediate user correction.

## Do

- Keep alerts brief; move detailed guidance to a linked doc.
- Include an icon to reinforce the tone for colour-blind users.
- Use `role="alert"` (applied automatically) so screen readers announce
  the content immediately.

## Don't

- Stack multiple alerts on top of each other — consolidate or use a toast
  for transient messages.
- Use alerts for success messages that dismiss automatically.
- Replace form validation errors with an alert alone — annotate the
  individual fields as well.
