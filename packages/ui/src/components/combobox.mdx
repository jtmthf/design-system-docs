# Combobox

An accessible autocomplete combobox built on Base UI. Combines a text input
with a filterable dropdown list. Supports single selection, multi-select chips,
and grouped options with keyboard navigation throughout.

## Usage

- **Default** — single-select with a chevron trigger; type to filter.
- **With Clear** — adds a clear (×) button to reset the value without reopening the list.
- **Grouped** — options organised into labelled sections with visual separators.
- **Multi Select** — renders selected values as removable chips inline with the input.

## Do

- Always provide a `placeholder` on `ComboboxInput` so users know what to type.
- Include `ComboboxEmpty` so the list communicates when no results match.
- Use `ComboboxGroup` and `ComboboxLabel` to organise long option lists.
- For multi-select, use `useComboboxAnchor` and pass `anchor` to `ComboboxContent`
  so the popup aligns with the chips container rather than the hidden input.

## Don't

- Mix `multiple` and a single `ComboboxInput` — use `ComboboxChips` for multi-select.
- Use a combobox when the list has only 2–4 fixed options — a `Select` is simpler.
