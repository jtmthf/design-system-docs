<ComponentPreview name="button-group-demo" />

Use a button group to fuse adjacent buttons or form controls — such as a split-button pattern or a search bar with a prefix icon — into a seamless visual block. Child elements lose their outer border-radius on adjacent edges automatically. `ButtonGroupText` provides a non-interactive label or icon segment, and `ButtonGroupSeparator` places a visual rule between sections. Use the `orientation` prop to switch between `"horizontal"` (default) and `"vertical"` layouts.

## Usage

```tsx twoslash
import { Button } from "@workspace/ui/components/button";
import { ButtonGroup } from "@workspace/ui/components/button-group";

export function Example() {
  return (
    <ButtonGroup>
      <Button variant="outline">Left</Button>
      <Button variant="outline">Center</Button>
      <Button variant="outline">Right</Button>
    </ButtonGroup>
  );
}
```

## Accessibility

- `ButtonGroup` renders with `role="group"` so assistive technology can announce the grouping.
- Each child button retains its own accessible label — the group role does not provide one automatically. Use `aria-label` on icon-only children.
- Focus order follows DOM order; ensure the visual and keyboard order match.
