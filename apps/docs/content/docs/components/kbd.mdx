Use `Kbd` to render a single keyboard key and `KbdGroup` to display a multi-key
chord. Both components adapt their background when placed inside a tooltip.

Renders native `<kbd>` elements with rounded, monospace styling. SVG icon
children are automatically sized to `12px`.

## Usage

```tsx twoslash
import { Kbd, KbdGroup } from "@workspace/ui/components/kbd";

export function Example() {
  return (
    <KbdGroup>
      <Kbd>Ctrl</Kbd>
      <Kbd>K</Kbd>
    </KbdGroup>
  );
}
```

## Accessibility

- Both `Kbd` and `KbdGroup` render semantic `<kbd>` elements, which screen
  readers announce as keyboard input.
- When used as a shortcut hint inside a menu item or tooltip, the parent element
  already provides the action label — `Kbd` supplements it visually.
- `pointer-events-none` and `select-none` are applied so keys cannot be
  accidentally clicked or selected during copy.
