# Hover Card

A preview card that appears when the user hovers over a trigger element. Use
HoverCards to surface supplemental information — such as user profiles or link
previews — without requiring a click.

## Usage

- **Default** — hovering a username link reveals a user profile card below the trigger.
- **Open By Default** — the card is visible on mount for layout previewing.
- **Top Placement** — the card opens above the trigger to avoid bottom-of-viewport clipping.

## Do

- Use hover cards for read-only supplemental information that enriches context.
- Adjust `openDelay` and `closeDelay` to balance responsiveness and accidental hover noise.
- Choose `side` based on available viewport space.

## Don't

- Don't put interactive controls inside a hover card — use a Popover instead.
- Don't rely solely on hover for mobile users; hover is not available on touch devices.
