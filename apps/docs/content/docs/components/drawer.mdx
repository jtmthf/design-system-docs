Use a drawer for secondary panels — navigation menus, filter sidebars, detail
views — that slide in from a viewport edge without requiring a full page
navigation. Drawers work especially well on mobile because they support
drag-to-dismiss.

Built on the Vaul `Drawer.Root` primitive. The `direction` prop controls which
edge the panel enters from (`"bottom"` by default, also `"top"`, `"left"`,
`"right"`). Compose with `DrawerTrigger`, `DrawerContent`, `DrawerHeader`,
`DrawerFooter`, `DrawerTitle`, and `DrawerDescription`.

## Usage

```tsx twoslash
import {
  Drawer,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@workspace/ui/components/drawer";
import { Button } from "@workspace/ui/components/button";

export function Example() {
  return (
    <Drawer>
      <DrawerTrigger asChild>
        <Button variant="outline">Open drawer</Button>
      </DrawerTrigger>
      <DrawerContent>
        <DrawerHeader>
          <DrawerTitle>Settings</DrawerTitle>
          <DrawerDescription>Manage your preferences.</DrawerDescription>
        </DrawerHeader>
        <DrawerFooter>
          <Button>Save</Button>
        </DrawerFooter>
      </DrawerContent>
    </Drawer>
  );
}
```

## Accessibility

- `DrawerTitle` provides the accessible name; `DrawerDescription` provides an
  optional description for screen readers.
- On touch devices, users can drag the panel toward the anchor edge to dismiss it.
- Always provide a `DrawerClose` button so keyboard users have an explicit way
  to close the drawer without relying on the <kbd>Escape</kbd> key.
