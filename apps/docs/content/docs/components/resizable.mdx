Use resizable panels for editor-style layouts — file trees next to code panes,
split-view comparisons, or resizable sidebars — where users benefit from
controlling the space allocated to each region.

Built on `react-resizable-panels`. Compose `ResizablePanelGroup` (the orientation
container), `ResizablePanel` (each pane), and `ResizableHandle` (the drag
separator) to create flexible split layouts.

## Usage

```tsx twoslash
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@workspace/ui/components/resizable";

export function Example() {
  return (
    <ResizablePanelGroup orientation="horizontal" className="h-64 rounded-lg border">
      <ResizablePanel defaultSize={50}>Left</ResizablePanel>
      <ResizableHandle withHandle />
      <ResizablePanel defaultSize={50}>Right</ResizablePanel>
    </ResizablePanelGroup>
  );
}
```

## Accessibility

- `ResizableHandle` renders a `separator` role element and supports keyboard
  resizing via <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> (horizontal) or
  <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> (vertical).
- Focus the handle with <kbd>Tab</kbd> and use arrow keys to resize without a
  pointer device.
- Set `withHandle` to render a visible grip bar so the drag affordance is
  discoverable by sighted users.
