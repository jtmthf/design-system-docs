Use a breadcrumb to help users understand and navigate the page hierarchy. It renders a `nav` element with `aria-label="breadcrumb"` and is composed of `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage`, `BreadcrumbSeparator`, and `BreadcrumbEllipsis`. `BreadcrumbLink` accepts a `render` prop for use with client-side router `Link` components.

## Usage

```tsx twoslash
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@workspace/ui/components/breadcrumb";

export function Example() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Settings</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

## Accessibility

- The `Breadcrumb` renders a `<nav aria-label="breadcrumb">` landmark that screen readers can navigate to directly.
- `BreadcrumbPage` carries `aria-current="page"` and `aria-disabled="true"` to communicate the current location.
- `BreadcrumbSeparator` and `BreadcrumbEllipsis` are hidden from assistive technology via `aria-hidden="true"`.
- When using an icon-only home link, provide an `aria-label` on the `BreadcrumbLink` so the destination is announced.
